GamePilot

Your PC Gaming Intelligence Platform

GamePilot sits alongside every game you play. It detects your hardware, identifies performance bottlenecks, recommends optimizations, and shows a real-time overlay with actionable insights. No cloud accounts, no API keys — it works by understanding what's on your screen and in your system.

Features

Intelligent optimization for every game

GamePilot runs passively in the background. Launch any game and it automatically starts working — no configuration required.

◉

Auto Game Detection

Detects 14+ games automatically from running processes — Minecraft, League of Legends, Tarkov, RuneScape, Path of Exile, CS2, Fortnite, VALORANT, and more. Plus full Steam library scanning.

▤

Real-Time Overlay

A transparent, always-on-top overlay floats over your game showing performance metrics, resource hog warnings, and recommendations. Toggleable with one click.

✶

Hardware Diagnostics

Profiles your CPU, RAM, GPU, and storage. Detects 20+ background processes that steal performance — Chrome, Discord, OBS, antivirus, RGB software, cloud sync — and warns you before launch.

→

Smart Recommendations

Rules-based optimization engine with safe, reversible actions. JVM tuning for Minecraft, performance mod suggestions, config optimization — all with preview, backup, and rollback.

❒

Mod Store

Search, download, and install mods directly from Modrinth. One-click performance mod installation. Enable, disable, and manage mods without leaving the app.

△

Passive Sessions

Automatically tracks your gaming sessions — no button clicks needed. Detects when a game starts and stops, records performance data, and generates post-session reports with trends and next steps.

What's New

v2.1 — Complete PRD Implementation

Every functional requirement from the product spec is now addressed.

FPS and TPS Tracking

Extracts FPS and TPS data from Minecraft logs during gameplay. Session reports show average FPS, 1% lows, and TPS with historical comparison.

Launch Profiles

Save JVM settings per instance. Auto-apply optimized settings on every launch. Profiles persist across restarts.

Conflict Detection

35-mod curated database detects incompatible combinations (Sodium vs OptiFine) and duplicate functionality (multiple minimaps). Config diff preview before applying changes.

Discord Sharing

Export optimization profiles and share them via Discord webhook. Other users can import profiles directly into their instances.

Crash Diagnosis

Automatically parses crash reports and game logs to identify out-of-memory errors, paging file issues, mod conflicts, and missing dependencies. Tells you exactly what went wrong and how to fix it.

Disk Management

Detects when game instances are on a full OS drive, recommends migration to a data drive, checks paging file adequacy, and scans for bloatware and temp files eating disk space. One-click instance migration between drives.
